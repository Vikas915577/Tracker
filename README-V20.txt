Winter Arc Tracker V20

V20 is a clean mobile-first shell over the existing offline-first tracker data.

Primary navigation:
- Today: intentionally compact Home screen with next action + habits
- Week: 7-day completion view
- Rank: global Arc League with Top 20 visible
- Profile: personal progress + share
- More: advanced tools kept away from Home

Rank visibility:
- Public leaderboard shows Top 20 profiles.
- The app may load up to 100 public rows so a user can still see their own position when outside Top 20.
- Ranking requires the optional community backend and a public profile.

Privacy:
- Private habits, journal, sleep, mood and PIN remain local and are not put into the public profile.

V20 keeps existing localStorage data and legacy tools intact.
